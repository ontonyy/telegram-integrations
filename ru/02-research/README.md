## Как читать выводы

В каждом сценарии отделены **возможности, описанные в документации**, от **предлагаемой архитектуры**. Страница поставщика подтверждает только перечисленные им функции. Слово «интеграция с Telegram» само по себе не означает вход в пользовательский аккаунт или доступ ко всем чатам.

По умолчанию не передавайте сообщения и файлы из Telegram в AI. Смотрите [AI и данные Telegram](ai-and-data.md) и проверяйте условия и согласия, нужные для конкретного сценария.
