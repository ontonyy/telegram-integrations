# Telegram, Claude, Codex и другие AI-системы

**Проверено:** 14 ноября 2026 года.

## Два разных сценария

### A. Telegram служит интерфейсом AI

`пользователь отправляет запрос боту → webhook проверяет обновление и согласие → сервис вызывает API модели → ответ отправляется ботом или остаётся черновиком менеджера`

Для справочного помощника можно искать только по утверждённым материалам базы знаний. Запрос пользователя можно обрабатывать только с ясным уведомлением и необходимым активным отзывным согласием. Для переписки Telegram Business нельзя отправлять сообщения или файлы сторонней модели без авторизации пользователя. Предпочтительно оставлять ответ черновиком для оператора.

### B. Telegram служит источником для AI

`AI-клиент → явно настроенный коннектор/сервис → разрешённые данные Telegram → ответ со ссылками на источники`

Здесь нужны реальный коннектор, авторизация и определённая область доступа. Bot API не является универсальным API истории. TDLib подключается как клиент Telegram с авторизованным аккаунтом, но не даёт доступ к недоступным этому аккаунту чатам и не отменяет условия Telegram. MCP — протокол; доступ зависит от инструментов сервера и настроенных учётных данных.

## Варианты Claude и Codex

| Вариант | Подтверждённые возможности | Что из этого не следует |
|---|---|---|
| Claude Messages API | Backend-приложение может отправлять Claude текст и изображения | Само по себе не подключает Telegram, не принимает обновления и не получает согласие участников |
| MCP в Claude Code | Claude Code поддерживает отдельно настроенные локальные stdio и удалённые HTTP/SSE серверы MCP | Нет стандартного Telegram MCP и доступа шире, чем явно предоставлено сервером |
| Codex CLI / SDK / app-server | Доступны ограниченные неинтерактивные CLI- и программные сценарии для задач кодирования | Это не отдельный «Codex API» для Telegram и не готовый коннектор |
| Удалённый MCP в OpenAI Responses API | Можно вызывать настроенный MCP-сервер с управлением инструментами и подтверждениями | Telegram не становится доступен без подходящего сервера и авторизации |
| Собственный сервис интеграции | Может принимать Bot API updates, применять правила, вызывать API AI и возвращать черновики/ответы | Нужны разработка, проверка условий и приватности, мониторинг и секреты |

**Состояние окружения на 14 ноября 2026 года:** установлены Codex CLI и Claude Code CLI. В списках MCP не было сервера Telegram. Подключённые инструменты приложений не предоставляли Telegram-коннектор, а Codex Document Control сообщил об отсутствии подключённой сессии документа. Это только снимок данного окружения, а не утверждение о доступности всех планов и продуктов. Перед работой проверьте `codex mcp list`, `claude mcp list` и настройки подключённых плагинов.

## Файлы и источники

Бот может получить файл, который пользователь отправил ему, после чего сервис может скачать его в пределах ограничений Bot API. Ограниченный pipeline может извлечь текст и проверить тип файла, а затем отправить выбранное содержимое модели при наличии разрешения. Не запускайте загруженный код и команды. Для файловых API провайдера проверьте сроки хранения и удаления, а идентификаторы файлов привязывайте к отправителю на сервере.

Чтобы показывать цитаты, храните идентификаторы и позиции источников в собственной разрешённой базе знаний и просите модель вернуть эти идентификаторы. Не обещайте ссылки на сообщения Telegram или доступ к истории, если коннектор этого не предоставляет.

## Ограничения Telegram для AI

Условия лицензирования контента Telegram запрещают сбор, индексацию и агрегирование данных, а также использование для разработки, улучшения, тестирования, сравнения или развёртывания AI/ML, кроме случаев явного, информированного, утвердительного и продолжающегося согласия всех затронутых пользователей для конкретного содержимого и чата/контекста. Условия для разработчиков ботов запрещают сбор сверх необходимого для сервиса и сбор для создания наборов данных, ML-моделей или AI-продуктов, включая сбор открытых групп и каналов. Они разрешают обрабатывать контент, добровольно отправленный пользователем боту напрямую, если цель явно раскрыта и есть индивидуальное явное, активное и отзывное согласие. Для данных Telegram Business передача третьей стороне, включая API, требует авторизации пользователя. Нельзя считать широкую индексацию архивов или передачу диалогов Business в Claude/OpenAI разрешённой только потому, что пользователь подключил аккаунт или оператор имеет доступ.
