# J24 — Офлайн-лаборатория подписанного webhook Chatwoot

## Результат

- Добавлен `POST /chatwoot/webhook` для узкого подмножества исходящих событий Chatwoot. До разбора события проверяется HMAC-SHA256 по timestamp, точке и точным исходным байтам тела.
- Фильтр запроса ограничивает размер Chatwoot-тела до его полной материализации Spring. В контроллере также остаётся защитное ограничение.
- Processor маршрутизирует только входящие текстовые `message_created` события от контакта. В handoff передаются ссылки на беседу и контакт; текст туда не передаётся.
- Дедупликация использует account ID и message ID из подписанного тела. Необязательный `X-Chatwoot-Delivery` служит только метаданными корреляции.
- Добавлены фиксированные синтетические векторы подписи, целевые тесты controller/processor/filter и команда `demoChatwootSupport`, работающая только с fake-объектами без сетевых запросов.

## Границы

Встроенный Telegram inbox Chatwoot владеет Telegram webhook, доставкой в Telegram, историей беседы и интерфейсом операторов. Этот Java webhook — отдельный канал Chatwoot → приложение. В примере нет API-клиента Chatwoot, credentials, живой настройки аккаунта или живой проверки. Содержимое тела временно разбирается, но handoff и fake recorder его не сохраняют. Реестр идемпотентности на 10 000 записей и состояние handoff хранятся только в памяти процесса: они не долговременны, не синхронизируются между экземплярами и не гарантируют production-идемпотентность. Пятиминутное окно timestamp ограничивает устаревшие повторы, но не заменяет долговременную дедупликацию.

Для реального развертывания нужны общий долговременный реестр идемпотентности с атомарными побочными действиями, явная политика повторов и хранения, отдельная аутентификация действий оператора, сетевые ограничения и проверенная интеграция API Chatwoot. Не следует считать этот учебный пример production-ready.

## Проверка

Из `examples/java-spring`:

```bash
./gradlew test --tests example.telegram.ChatwootWebhookSignatureValidatorTest --tests example.telegram.ChatwootWebhookControllerTest --tests example.telegram.ChatwootWebhookProcessorTest --tests example.telegram.ChatwootSupportHandoffTest --tests example.telegram.TelegramWebhookBodyLimitFilterTest
./gradlew demoChatwootSupport
./gradlew test
```

Тесты и демонстрация используют только синтетические ID, текст и секреты. Аккаунты Telegram и Chatwoot не подключались.
