# J02 — Отправка сообщений Bot API через Java HttpClient

[English](../../../tasks/completed-issues/J02.md) · [GitHub issue #2](https://github.com/ontonyy/telegram-integrations/issues/2)

## Что сделано

`TelegramBotClient` вызывает Bot API напрямую через `HttpClient` из Java. Пример охватывает текст, HTML-безопасные уведомления, inline-клавиатуры, ответы на callback и редактирование сообщений без bot framework.

## Как это работает

Клиент берёт токен из конфигурации, формирует `/bot<TOKEN>/<method>` и отправляет JSON через `HttpTransport`. `TELEGRAM_SEND_ENABLED` по умолчанию равен `false`; включение без токена завершается безопасным отказом. Тесты используют локальный HTTP server и проверяют метод, путь, заголовки, тело и обработку ошибок. Автоматических повторов нет: после timeout исход доставки может быть неизвестен.

Проверка: `./examples/java-spring/gradlew -p examples/java-spring test --tests example.telegram.TelegramBotClientHttpTest`.

## Применение в проекте

Подходит небольшому Java-сервису для уведомлений о сборке, инциденте или состоянии заказа. Пользователь должен сначала открыть боту личный чат или добавить бота в чат с правом писать. Для надёжной доставки добавьте ограниченную очередь с учётом `retry_after`; не помещайте в сообщения логи и персональные данные.
