# J01 — Воспроизводимая основа Java-примеров без credentials

[English](../../../tasks/completed-issues/J01.md) · [GitHub issue #1](https://github.com/ontonyy/telegram-integrations/issues/1)

## Что сделано

Добавлен общий проект примеров на Java 25 / Spring Boot, тесты на синтетических данных и точки подмены внешних HTTP-вызовов. Credentials Telegram и AI необязательны; отправка сообщений Telegram выключена по умолчанию.

## Как это работает

`HttpTransport` отделяет бизнес-логику от настоящего `JdkHttpTransport`. Тесты внедряют транспорт в памяти или локальный mock HTTP server. Demo-профиль использует только публичный локальный placeholder webhook. Сканер credentials проверяет распространённые форматы секретов и игнорирует локальные файлы аккаунта/сессии.

Из корня репозитория: `./examples/java-spring/gradlew -p examples/java-spring clean test`.

## Применение в проекте

Используйте такую основу для адаптера внешнего провайдера: узкий transport/gateway интерфейс, тестирование запроса и ошибок на синтетических данных, отдельная конфигурация live-адаптера. Секреты храните в переменных окружения или secret manager. In-memory состояние замените на общее долговременное хранилище при нескольких экземплярах или необходимости переживать перезапуски.
