# J12 — Изучение авторизации TDLib Java отдельно от Spring

[English](../../../tasks/completed-issues/J12.md) · [GitHub issue #12](https://github.com/ontonyy/telegram-integrations/issues/12)

## Что сделано

Отдельный необязательный Java/JNI пример показывает состояния авторизации TDLib, жизненный цикл клиента, ограниченный просмотр названий чатов и инструкции удаления локальной сессии. Он изолирован от обычного Bot API/Spring-примера.

## Как это работает

Основной поток зависит от `TdLibPort`, поэтому fake-port тесты проверяют переходы состояний без JNI, сети и credentials. Отдельный необязательный source set содержит адаптер официального TDLib Java API. Ручной запуск запрашивает данные входа интерактивно и показывает не более десяти названий чатов основного списка; тела сообщений не загружаются, история не индексируется, отправки и AI нет.

## Применение в проекте

Выбирайте TDLib, если действительно создаёте клиент под пользовательский аккаунт. Соберите native-библиотеку для поддерживаемых ОС/JVM, защитите базу сессии и ключ шифрования, предусмотрите logout и отзыв устройства в Telegram, а доступ аккаунта привяжите к явно разрешённым действиям приложения. Сам доступ к чату не разрешает внешнюю обработку данных.
