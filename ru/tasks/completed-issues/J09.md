# J09 — Grafana alert и подтверждение на уровне приложения

[English](../../../tasks/completed-issues/J09.md) · [GitHub issue #9](https://github.com/ontonyy/telegram-integrations/issues/9)

## Что сделано

Java-пример принимает Grafana alert webhook, отправляет короткие сообщения firing/resolved и предлагает разрешённому пользователю отметить, что он увидел alert.

## Как это работает

Общий servlet filter ограничивает тело `POST /grafana/webhook` до привязки в Spring. Затем контроллер проверяет HMAC-SHA256 и timestamp по сохранённым исходным байтам и форматирует выбранные labels и проверенный source URL. Авторизованный пользователь может подтвердить запись alert в приложении. Повторное подтверждение отклоняется как уже обработанное.

## Применение в проекте

Для уведомлений без обратных действий может хватить встроенного Telegram contact point Grafana. Java адаптер полезен для собственных фильтров, подтверждений приложения или backend-действия. Настройте webhook Grafana и secret, чат назначения и узкий allowlist дежурных/менеджеров.
