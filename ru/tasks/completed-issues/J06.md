# J06 — Уведомления Telegram о результате GitHub Actions

[English](../../../tasks/completed-issues/J06.md) · [GitHub issue #6](https://github.com/ontonyy/telegram-integrations/issues/6)

## Что сделано

Добавлено опциональное уведомление GitHub Actions о завершении Java workflow. Сообщение содержит результат и ссылку на конкретный запуск, но не логи.

## Как это работает

Workflow запускает тесты на pull request, но не шлёт Telegram-уведомления для PR. При push в `master` или ручном запуске на `master` отправка включается только при наличии `TELEGRAM_BOT_TOKEN` в GitHub secrets и `TELEGRAM_CHAT_ID` в repository variables. Форматирование и выбор режима проверяются локально без credentials.

## Применение в проекте

Перенесите шаблон на итоги build/test/deploy. Выдавайте job только нужные permissions, храните bot token как secret и не передавайте его коду недоверенных fork. Получатель должен сначала начать диалог с ботом или добавить его в разрешённую группу. Реальную доставку проверяйте в отдельно разрешённом приватном чате.
