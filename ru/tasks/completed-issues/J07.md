# J07 — Отправка заявки Mini App в Java backend

[English](../../../tasks/completed-issues/J07.md) · [GitHub issue #7](https://github.com/ontonyy/telegram-integrations/issues/7)

## Что сделано

В примере есть форма Mini App: она отправляет синтетическую заявку, получает reference и позволяет читать статус только владельцу.

## Как это работает

Браузер передаёт исходную `Telegram.WebApp.initData`; backend проверяет HMAC и свежесть, затем получает Telegram user ID из подписанных данных. `initDataUnsafe` и присланному браузером ID доверия нет. `MiniAppRequestService` отдельно проверяет владельца при запросе статуса. Контекст запуска из группы не даёт общего доступа и не открывает историю сообщений.

## Применение в проекте

Выбирайте Mini App, когда клиенту или сотруднику нужна проверенная форма, заказ, расписание или более богатый мобильный интерфейс, чем кнопки чата. Разместите приложение по HTTPS, настройте URL запуска, проверяйте initData на сервере и отдельно проверяйте доступ к аккаунту и записи. Перед production замените память процесса на постоянное хранилище.
