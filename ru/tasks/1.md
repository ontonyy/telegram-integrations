# Задача 1: добавить пять примеров интеграции на Java

## Цель

Добавить небольшой запускаемый набор примеров разных способов подключить Telegram к Java-проекту. Каждый пример должен объяснять свою задачу и критерии выбора.

## Примеры

1. **Отправка сообщения через Java HttpClient и Bot API** — уведомление о сборке, развёртывании или состоянии сервиса без Telegram-фреймворка.
2. **Приём команд через webhook Spring Boot** — небольшой allowlist, например `/status` и `/help`, проверка webhook secret и безопасная обработка ответа.
3. **Mini App с Java backend** — проверка `initData` на сервере, пример панели или структурированного действия.
4. **TDLib из Java для авторизованного пользовательского клиента** — асинхронная инициализация и авторизация, затем список чатов текущего пользователя. Без скрытого сбора или незапрошенных действий.
5. **Приём и обработка присланного пользователем файла через бота** — обработка update Bot API с лимитом размера, очисткой и примером безопасной обработки.

## Требования

- Для каждого примера — короткий README: цель, требования, запуск и доступные данные.
- Только вымышленные данные. Запрещено коммитить токен бота, API ID/hash, телефон, код входа, TDLib-сеанс/БД или любые настоящие секреты.
- Секреты читать при запуске из переменных окружения или secret manager. Не добавлять заполненный `.env` или тестовый файл с секретами.
- Хранить TDLib-сеанс вне репозитория и объяснить, что он даёт доступ уровня пользовательского аккаунта.
- Проверять права и пользовательский ввод на сервере; ограничивать команды и действия явным allowlist.
- По умолчанию не отправлять сообщения/файлы Telegram и другой контент платформы в AI/ML. До AI-примера проверить условия Telegram и необходимые согласия/контроль приватности.
- Примеры должны быть небольшими и самостоятельными; локальная или смоделированная проверка не доказывает работу с Telegram в реальном окружении.

## Готово, когда

- У каждого из пяти примеров есть понятные инструкции установки и очистки.
- В отслеживаемых файлах нет реальных секретов или данных аккаунта.
- Документация сравнивает Bot API, Mini Apps и TDLib и описывает границы доступа.
- Сборка и базовые проверки проходят на выбранной Java-конфигурации.
