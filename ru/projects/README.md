# Проектные заметки по интеграции Telegram

В этом каталоге общие исследования переведены в идеи, зависимости и будущие заготовки задач для конкретных проектов. Это предложения, а не планы реализации, утверждённое поведение продукта, Jira-задачи или доказательство работающей интеграции.

Для изучения идей см. [брейншторм возможностей Telegram для CVNoor](../01-brainstorm/cvnoor-telegram-opportunities.md).

## Проекты

- [Продукт CVNoor](cvnoor/README.md) — сценарии кандидатов и работодателей, поддержка и сервис; [приоритеты пилотов](cvnoor/telegram-pilot-priorities.md) отделяют существующие внутренние алерты API от будущих клиентских сценариев.
- [CVNoor API](cvnoor-api/README.md) — границы интеграции backend, доставка уведомлений и операционные процессы.

В каждом проекте есть список кандидатов в задачи. Перед созданием тикетов проверьте актуальное состояние продукта, решения о приватности, контракты API, приоритеты владельца и зависимости. В репозитории не должны появляться Telegram-секреты или клиентские данные.
