# Заготовки задач по Telegram для CVNoor

**Статус:** предложенные заготовки, не Jira-тикеты и не утверждённый план работ. Идентификаторы ниже локальные. В исходниках API уже есть внутренние Bot API-уведомления об операциях и релизах; сначала сверить CVN-521/CVN-529/CVN-550 и их проверку, чтобы не дублировать работу. Перед созданием тикета сверить текущие контракты фронтенда/бэкенда, приватность, приоритеты владельца и Jira.

## Исследование и защита пользователей

| Ссылка | Результат будущего тикета | Готово, когда | Зависимости/примечания |
|---|---|---|---|
| CVN-TG-01 | Отделить внутренние алерты от клиентских уведомлений | Текущие release/workflow/API-алерты перечислены отдельно от идей для кандидатов/работодателей/поддержки; согласованы получатель, цель, ценность, канал и исключения | Сначала сверить CVN-521/CVN-529/CVN-550; владелец продукта; сравнить с email/in-product |
| CVN-TG-02 | Определить правила связи с кандидатами и защиты молодых пользователей | Утверждены возраст, текст opt-in, частота, тихое время, отличие маркетинга, жалобы/модерация и хранение | Продукт/юрист/ответственный за безопасность; аудитория молодая |
| CVN-TG-03 | Определить раскрытие данных в сообщениях Telegram | Матрица текста и полей для кандидата/работодателя/сотрудника; чувствительные поля исключены; описаны защищённые ссылки | Сверить с `docs/privacy-disclosure-matrix.md`; приватность/юрист |
| CVN-TG-04 | Выбрать канал поддержки и модель работы операторов | Решены бот/Business/helpdesk, отправитель, доступ операторов, хранение и эскалация | Руководитель поддержки; проверка поставщика/приватности |

## Качество и запуск

| Ссылка | Результат будущего тикета | Готово, когда | Зависимости/примечания |

| CVN-TG-15 | Разделить гарантии внутренних алертов и клиентских уведомлений | Описаны текущий best-effort in-memory sender и возможные потери; retry/ledger пользовательских сообщений заданы отдельно, без неявного изменения alert-контракта | Согласовать с backend outbox/provider; не логировать секреты и тела сообщений |

| CVN-TG-17 | Решить, нужен ли Mini App для подтверждённой проблемы мобильного UX | Исследование показывает недостающий сценарий; прототип сравнили с адаптивным сайтом | Не создавать Mini App только потому, что Telegram это позволяет |

## Предлагаемый порядок

1. Сверить существующие алерты/CVN-521, CVN-529 и CVN-550; затем CVN-TG-01—04: решение о клиентских сообщениях и защита.
2. CVN-TG-05 и небольшой пилот CVN-TG-10 — только после безопасного дизайна привязки и раскрытия.
3. CVN-TG-15 и CVN-TG-16 до расширения.
4. Добавлять уведомления кандидатам, поддержку, дайджесты и внутренние действия после отдельных проверок.

Этот backlog не разрешает изменения фронтенда/бэкенда, настройку провайдера, хранение секретов, развёртывание или контакт с клиентами. См. [обзор продукта](README.md) и [заметки по API](../cvnoor-api/README.md).
