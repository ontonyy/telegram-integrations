# Task 1: Add five Java integration examples

## Goal

Add a small, runnable set of Java examples that demonstrates different ways a Java project can integrate with Telegram. Keep each example focused and explain when to choose it.

## Examples to implement

1. **Send a message with Java HttpClient and the Bot API**  
   Post a build, deployment, or service-status notification without a Telegram framework.

2. **Receive bot commands with a Spring Boot webhook**  
   Handle a small allowlist such as `/status` and `/help`; show webhook secret validation and safe response handling.

3. **Expose a Telegram Mini App to a Java backend**  
   Validate Telegram `initData` server-side, then return a sample dashboard or accept a structured action request.

4. **Use TDLib from Java for a user-authorized client workflow**  
   Demonstrate asynchronous client initialization and authorization, then list or display chats available to the signed-in account. Do not add hidden collection or unattended user actions.

5. **Receive and process a user-submitted file through a bot**  
   Show the Bot API update flow and a bounded file-processing example with explicit size limits and cleanup.

## Requirements

- Include a short README for each example with its purpose, prerequisites, how to run it, and what it can access.
- Use fake sample data only. Never include a real bot token, API ID/hash, phone number, login code, TDLib session/database, or other credential.
- Read runtime secrets from environment variables or a secret manager. Do not commit a populated `.env` file or credential-bearing test fixture.
- Keep TDLib session storage outside the repository and document that a session grants account-level access.
- Validate authorization and user input server-side. Restrict commands and actions to an explicit allowlist.
- Do not send Telegram messages, files, or other Telegram-origin data to AI/ML systems by default. Before adding any AI example, review Telegram's current terms and implement the required scoped consent and privacy controls.
- Keep examples small enough to understand independently and do not claim that a mocked or local run verifies a live Telegram integration.

## Done when

- All five examples have clear setup and cleanup instructions.
- No real credentials or account data are present in tracked files.
- The project documents which examples use Bot API, Mini Apps, and TDLib, and what each path can access.
- Build and basic checks pass for the chosen Java setup.
