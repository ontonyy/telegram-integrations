# J06 — Notify Telegram about GitHub Actions results

[Русская версия](../../ru/tasks/completed-issues/J06.md) · [GitHub issue #6](https://github.com/ontonyy/telegram-integrations/issues/6)

## What was delivered

The repository includes an opt-in GitHub Actions notification for a completed Java sample workflow. The message reports the result and links to the exact run without sending logs.

## How it works

The workflow runs tests on pull requests but skips Telegram delivery for all PRs. On `master` pushes or manual runs on `master`, it enables sending only when `TELEGRAM_BOT_TOKEN` is present as a GitHub secret and `TELEGRAM_CHAT_ID` is configured as a repository variable. Formatting and the send-mode decision are locally testable without credentials.

## Use this in a real project

Copy the workflow pattern for build, test, or deploy summaries. Grant only the permissions the job needs, keep the bot token out of variables and source files, and never expose it to untrusted fork code. The recipient must first start the bot or add it to an authorized group. Test a real delivery only in a separately approved private chat.
