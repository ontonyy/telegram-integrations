# J14 — Capture a Telegram sales lead in HubSpot

[Русская версия](../../ru/tasks/completed-issues/J14.md) · [GitHub issue #14](https://github.com/ontonyy/telegram-integrations/issues/14)

## What was delivered

The private-chat demo discloses the data flow, asks for consent, and upserts customer-entered contact fields to HubSpot. A manager gets only the queue name and CRM contact reference.

## How it works

The commands are `/sales` → `/sales-consent` → `/sales-submit email|first name|last name|company`. The Java adapter uses the HubSpot `2026-09` contact batch-upsert endpoint keyed by email and sets a configured owner. It does not copy a Telegram ID/profile/history, create a deal, or grant marketing subscription consent. `/sales-stop` revokes the volatile demo consent.

## Use this in a real project

Use it as a first-step lead intake, then connect a real CRM owner/team queue and an authorized manager UI. Configure the least-privilege contacts-write scope and verify portal-specific required fields and owner IDs. Add durable consent, retention, update policy, idempotency/outbox, and a privacy notice before live writes.
