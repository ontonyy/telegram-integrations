# J10 — Accept small user-submitted text files safely

[Русская версия](../../ru/tasks/completed-issues/J10.md) · [GitHub issue #10](https://github.com/ontonyy/telegram-integrations/issues/10)

## What was delivered

The bot accepts selected text-file formats in a private chat only after disclosure and explicit consent. It checks metadata and size, downloads through the Bot API file flow, counts lines and detects a simple stack-trace pattern, then deletes the temporary file.

## How it works

`/file-help` explains processing, `/file-consent` enables it, and `/file-stop` revokes consent. The service checks the extension, MIME type, declared and downloaded size, UTF-8 text, path safety, and private temporary-directory permissions. It treats content as data: it does not execute, render, extract archives, or send the file to AI.

## Use this in a real project

This pattern can triage short logs or source snippets from a support customer or employee. Set a strict size/type allowlist, encrypt or restrict temporary storage, define retention, and move processing to a bounded worker if volume grows. Add malware scanning and a privacy policy where the product requires them.

## Implementation and limits

See [`FileIntakeService`](../../examples/java-spring/src/main/java/example/telegram/FileIntakeService.java), [`BotApiTelegramFileGateway`](../../examples/java-spring/src/main/java/example/telegram/BotApiTelegramFileGateway.java), and [file intake tests](../../examples/java-spring/src/test/java/example/telegram/FileIntakeWebhookTest.java). Tests use fake file metadata and synthetic text; the sample is not a PDF/document parser and does not test a live Telegram download.

The service holds an OS file lock for each active upload. On a later intake, it removes abandoned upload workspaces whose lease is no longer locked, while leaving locked workspaces and directories with unexpected contents untouched. This recovery depends on the configured filesystem honoring Java cross-process file locks; verify that property before using a shared or network filesystem. The private temp root retains a `.maintenance.lock` coordination file.
