# J08 — Route selected Jira Cloud events to Telegram

[Русская версия](../../ru/tasks/completed-issues/J08.md) · [GitHub issue #8](https://github.com/ontonyy/telegram-integrations/issues/8)

## What was delivered

The Java sample accepts Jira issue-created and issue-updated webhooks, filters for configured project/type/status changes, and sends a concise link-bearing notification.

## How it works

`POST /jira/webhook` checks the configured HMAC signature against the raw request body, enforces a payload limit, and de-duplicates Jira's webhook identifier. The formatter includes a validated issue key, clipped and escaped summary, selected change, and issue link; it omits comments and full descriptions.

## Use this in a real project

Register an HTTPS Jira Cloud webhook for only the desired events. Configure a high-entropy webhook secret, project/type/status filters, and a bot destination with write access. Treat Jira source fields as untrusted input and monitor retries and notification volume.
