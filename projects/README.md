# Project-specific Telegram integration notes

This directory turns the general [Telegram ecosystem research](../02-research/README.md) into project-specific opportunities, dependencies and future ticket seeds. These are proposals, not implementation plans, approved product behavior, Jira tickets, or evidence of live Telegram integrations.

For idea exploration, see the [CVNoor Telegram brainstorm](../01-brainstorm/cvnoor-telegram-opportunities.md).

## Projects

- [CVNoor product](cvnoor/README.md) — candidate and employer journeys, support and service opportunities; [pilot priorities](cvnoor/telegram-pilot-priorities.md) distinguishes the API's current internal alerts from future user-facing ideas.
- [CVNoor API](cvnoor-api/README.md) — backend integration boundaries, notification delivery and operational workflows.

Each project has a candidate task backlog. Use it to shape and prioritize tickets later. Before creating tickets, verify the current product/privacy decisions, repository state, relevant API contracts, owner priorities and prerequisites. No Telegram credentials or customer data belong here.
